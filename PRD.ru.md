# PRD: Cliprigo

Кроссплатформенное десктоп-приложение для скачивания видео с YouTube через `yt-dlp` с историей скачанного.

## 1. Цель

Дать простой и лёгкий GUI поверх `yt-dlp`: вставил ссылку → выбрал формат → скачал. Все скачивания сохраняются в историю, чтобы ничего не потерять и не скачать дважды.

**Принципы:** лёгкость (маленький бинарник, быстрый старт), минимум настроек, ничего не нужно ставить руками — `yt-dlp`, `ffmpeg` и JS-рантайм приложение подтягивает само.

## 2. Целевые платформы

| ОС            | Архитектуры |
| ------------- | ----------- |
| Windows 10+   | x64, arm64  |
| macOS 12+     | arm64, x64  |
| Linux (glibc) | x64, arm64  |

## 3. Стек

- **Tauri 2** (Rust backend)
- **Svelte 5 + TypeScript + Vite** (frontend)
- **SQLite** через `rusqlite` (feature `bundled`) — история и настройки
- Плагины Tauri: `dialog` (выбор папки), `opener` (открыть файл/папку/ссылку)
- i18n: RU + EN (лёгкая собственная реализация на словарях, без тяжёлых библиотек)
- Тема: светлая/тёмная по системной (`prefers-color-scheme`)

## 4. Внешние зависимости (управляются приложением)

Хранятся в `<app_data_dir>/bin/`. Приложение никогда не полагается на версии из PATH.

### 4.1 yt-dlp

- Источник: GitHub Releases `yt-dlp/yt-dlp`, `releases/latest`.
- Ассет под систему:
  - Windows x64 → `yt-dlp.exe`, Windows arm64 → `yt-dlp_arm64.exe`
  - macOS → `yt-dlp_macos` (universal)
  - Linux x64 → `yt-dlp_linux`, Linux arm64 → `yt-dlp_linux_aarch64`
- Проверка целостности по `SHA2-256SUMS` из того же релиза.
- На Unix — `chmod +x`. На macOS файлы, которые приложение скачивает само (не через браузер), не получают атрибут `com.apple.quarantine`, поэтому Gatekeeper их не проверяет. Ради надёжности: если атрибут всё же есть — снять; если `codesign -v` не проходит — сделать ad-hoc подпись `codesign --force -s -` (на Apple Silicon неподписанный бинарник не запустится).
- **Обновление:** при каждом старте (не чаще раза в N часов) сверять тег последнего релиза с установленным; если новее — скачать в фоне и атомарно заменить (скачивание во временный файл → rename). Кнопка «Проверить обновления» в настройках. Во время активных загрузок замена откладывается.

### 4.2 ffmpeg (+ ffprobe)

Нужен для склейки лучшего видео+аудио, конвертации в mp3/m4a, встраивания обложки/метаданных.

- Источник для всех ОС: GitHub Releases `shaka-project/static-ffmpeg-binaries`, `releases/latest`. Отдельные статические бинарники без архивов:
  - macOS → `ffmpeg-osx-arm64` / `ffmpeg-osx-x64` (+ `ffprobe-*`)
  - Linux → `ffmpeg-linux-x64` / `ffmpeg-linux-arm64`
  - Windows → `ffmpeg-win-x64.exe` (на Windows arm64 работает через эмуляцию x64)
- Запасной источник для Windows/Linux: `yt-dlp/FFmpeg-Builds` (архивы с `ffmpeg`/`ffprobe`).
- Скачивается при первом запуске, обновляется только вручную из настроек (меняется редко).
- Передаётся в yt-dlp через `--ffmpeg-location`.

### 4.3 JS-рантайм (Deno)

Актуальные версии yt-dlp требуют внешний JS-рантайм для полноценной работы с YouTube (решение JS-челленджей). Без него часть форматов недоступна.

- Источник: GitHub Releases `denoland/deno`, ассет `deno-<target>.zip`.
- Передаётся через `--js-runtimes deno:<path>`.
- Обновление — как у ffmpeg (вручную).

### 4.4 Первый запуск

Экран «Подготовка»: прогресс скачивания трёх компонентов, понятные ошибки (нет сети, GitHub rate limit) и кнопка «Повторить». Пока компоненты не готовы — скачивание видео недоступно.

## 5. Функциональные требования

### 5.1 Добавление загрузки

1. Поле ввода ссылки + кнопка «Вставить» и поддержка Ctrl/Cmd+V.
2. Валидация: ссылка YouTube (`youtube.com/watch`, `youtu.be`, `shorts`, `playlist`, `@channel`, `music.youtube.com`). Прочие ссылки — предупреждение, но разрешить (yt-dlp умеет многое).
3. После вставки — получение метаданных (`yt-dlp -J`, для плейлистов `--flat-playlist`): название, автор, длительность, превью, список доступных качеств.
4. **Проверка дубликата:** если видео (по `video_id`) уже есть в истории со статусом «завершено» — предупреждение с вариантами «Скачать снова» / «Открыть существующий» / «Отмена».
5. Выбор формата:
   - **Видео (по умолчанию)** — лучшее качество, контейнер mp4 (`-f "bv*+ba/b" --merge-output-format mp4`, с приоритетом совместимых кодеков через `-S`).
   - **Качество** — список высот, реально доступных у видео (2160/1440/1080/720/480/360), `-S res:<h>`.
   - **Только аудио** — mp3 или m4a (`-x --audio-format ...`).
6. **Плейлисты/каналы:** показать список видео (с чекбоксами, по умолчанию все) и общее количество; каждое видео становится отдельной задачей в очереди, сгруппированной под плейлистом. Дубликаты внутри плейлиста помечаются и по умолчанию сняты.
7. Папка сохранения — по умолчанию из настроек, можно переопределить для конкретной загрузки.

### 5.2 Очередь загрузок

- Очередь с параллельностью N (по умолчанию 2, настраивается 1–5).
- На задачу: превью, название, прогресс-бар, %, скорость, ETA, размер, стадия (загрузка / склейка / конвертация).
- Действия: отменить, повторить (для упавших), открыть папку (для готовых).
- Прогресс берётся из `--newline --progress-template` (JSON-строки в stdout), итоговый путь — из `--print after_move:filepath`.
- Отмена убивает процесс (включая дочерний ffmpeg) и удаляет `.part`-файлы.
- При закрытии приложения с активными загрузками — подтверждение.
- Незавершённые задачи после перезапуска помечаются «прервано» и их можно повторить.

### 5.3 История

Каждая загрузка — запись в SQLite. Поля:

| Поле                        | Описание                                                                                      |
| --------------------------- | --------------------------------------------------------------------------------------------- |
| id                          | PK                                                                                            |
| video_id                    | ID видео на YouTube (для поиска дублей)                                                       |
| url                         | исходная ссылка                                                                               |
| title, uploader             | название, автор                                                                               |
| duration                    | длительность, сек                                                                             |
| thumbnail_url               | URL превью (картинка кэшируется локально)                                                     |
| format                      | `video` / `audio_mp3` / `audio_m4a` + качество                                                |
| file_path                   | путь к итоговому файлу                                                                        |
| file_size                   | размер, байт                                                                                  |
| status                      | `queued` / `downloading` / `processing` / `completed` / `failed` / `canceled` / `interrupted` |
| error                       | текст ошибки (для failed)                                                                     |
| playlist_id, playlist_title | если из плейлиста                                                                             |
| created_at, completed_at    | даты                                                                                          |

Возможности:

- Список, новые сверху, с превью.
- Поиск по названию/автору, фильтр по статусу.
- Действия над записью: открыть файл, открыть папку, скопировать ссылку, открыть на YouTube, скачать заново, удалить запись, удалить запись + файл (с подтверждением).
- Индикатор «файл не найден», если файл удалили/переместили вручную (проверка при показе).

### 5.4 Настройки

- Папка загрузок по умолчанию (по умолчанию — системная «Загрузки»).
- Формат и качество по умолчанию.
- Количество параллельных загрузок.
- Шаблон имени файла (по умолчанию `%(title)s [%(id)s].%(ext)s`).
- Язык (RU/EN/системный).
- Блок «Компоненты»: версии yt-dlp / ffmpeg / deno, кнопки «Проверить обновления» и «Переустановить».
- Автопроверка обновлений yt-dlp при старте (вкл/выкл).

## 6. UI (экраны)

Одно окно, три вкладки:

1. **Загрузка** — поле ссылки, карточка превью с выбором формата, ниже — активная очередь.
2. **История** — поиск, фильтр, список записей.
3. **Настройки**.

Плюс экран первого запуска (подготовка компонентов). Минимальный размер окна ~720×520.

## 7. Нефункциональные требования

- Размер установщика (без внешних бинарников) — цель < 15 МБ.
- Холодный старт < 1.5 с.
- UI не блокируется во время загрузок и обновлений; всё тяжёлое — в Rust async (tokio).
- Процессы yt-dlp запускаются без консольного окна на Windows (`CREATE_NO_WINDOW`).
- Аргументы передаются массивом, никакой интерполяции в shell.
- Логи в `<app_data_dir>/logs/`, последние ~1 МБ, кнопка «Открыть логи» в настройках.

## 8. Вне скоупа MVP

- Субтитры, cookies из браузера, авторизация.
- Автовставка ссылки из буфера обмена.
- Обрезка видео, конвертация в произвольные форматы.
- Пауза/возобновление (кроме повтора — yt-dlp сам продолжит `.part`).
- Автообновление самого приложения.
- Подпись приложения (Apple Developer ID + нотаризация, Windows code signing).
- Мобильные платформы.

## 9. Риски

| Риск                                            | Митигация                                                                                                                                                                                    |
| ----------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| YouTube ломает yt-dlp                           | Автообновление yt-dlp при старте; понятное сообщение «обновите yt-dlp» при типичных ошибках                                                                                                  |
| GitHub API rate limit (60 req/ч)                | Для скачивания использовать `releases/latest/download/<asset>` (редирект, не API); тег узнавать по редиректу `releases/latest`                                                               |
| macOS Gatekeeper блокирует бинарники            | Снятие quarantine-атрибута, ad-hoc подпись при необходимости                                                                                                                                 |
| Приложение не подписано (MVP)                   | macOS: инструкция в README («Открыть всё равно» или `xattr -dr com.apple.quarantine`); Windows: SmartScreen → «Подробнее» → «Выполнить в любом случае»; Linux: не нужно. Подпись — после MVP |
| Антивирусы на Windows ругаются на скачанные exe | Проверка SHA256, понятная ошибка с инструкцией                                                                                                                                               |
| Требование JS-рантайма изменится                | Путь и флаг рантайма изолированы в одном модуле                                                                                                                                              |
| Правовые аспекты                                | В приложении не встраиваются бинарники — скачиваются с официальных источников; дисклеймер в README                                                                                           |

## 10. Критерии готовности MVP

- На чистой Windows/macOS/Linux приложение само ставит yt-dlp, ffmpeg, deno и скачивает видео в 1080p mp4 и mp3.
- Плейлист из 10+ видео скачивается через очередь с параллельностью 2.
- История переживает перезапуск, работает поиск, дубликат даёт предупреждение.
- Отмена загрузки не оставляет мусорных файлов.
